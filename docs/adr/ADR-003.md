# ADR-003

## Title

Execution Pipeline

## Status

Accepted

## Decision

Every execution request passes through middleware before reaching the execution engine.

ExecutionRequest

↓

ExecutionPipeline

↓

Middleware

↓

ExecutionEngine

↓

RuntimeCoordinator

## Consequences

Allows

- tracing
- logging
- retries
- authorization
- metrics
- future middleware without changing the engine
